# The Practice Court

A searchable directory of high-signal sources for tennis, table tennis, padel, and the wider racket-sport world.

Source for a directory prototype. The standalone GitHub Pages host was
retired; the retained directory is part of the consolidated Tennis CV site.

## Why it exists

Useful coaching, analysis, and reporting are often buried beneath repetitive feeds and low-context clips. The Practice Court keeps a smaller collection of sources that consistently teach, explain, or reveal something worth following.

## Features

- Search across publishers, coaches, analysts, and creators
- Filter by sport, source type, and topic
- Follow sources locally without creating an account
- Open the original source directly
- Responsive static site with no backend dependency

## Current status

The directory source includes 38 curated sources. The next product milestone is a lightweight submission and review flow so coaches and players can recommend additions without lowering the quality bar.
